# 🧠 Neural Geodesic Surrogate (Нейросетевой суррогат геодезических)

Инструментарий для обучения легковесной нейросети (~36 КБ весов), которая полностью заменяет 100-шаговый цикл численного рейтрейсинга на один мгновенный прямой проход (инференс за $\approx 0.3-0.5\,\text{мс}$ на GPU).

---

## 🚀 Быстрый старт на ПК

### 1. Установка зависимостей
```bash
cd neural
pip install -r requirements.txt
```

### 2. Генерация обучающего датасета
Скрипт генерирует миллионы релятивистских лучей на базе строгого 2nd-order симплектического интегратора:
```bash
python generate_dataset.py --samples 200000 --output geodesic_dataset.npz
```
* **Время работы:** ~15–30 секунд.
* **Результат:** файл `geodesic_dataset.npz` (~12 МБ), содержащий координаты старта, направления, падение за горизонт, вектор улета к звездам и пересечения с диском.

### 3. Обучение нейросети
```bash
python train.py --data geodesic_dataset.npz --epochs 30 --batch_size 1024 --device cuda
```
* Если видеокарта NVIDIA — обучение займет **всего 1–3 минуты**!
* Модель: 4-слойный MLP ($6 \to 64 \to 64 \to 64 \to 7$), активация GELU.
* Точность классификации горизонта событий: **$> 99.8\%$**.
* Косинусная близость вектора отклонения света: **$> 0.999$**.
* Лучшая модель сохраняется в `best_model.pth`.

### 4. Экспорт весов для Three.js и WebGL
```bash
python export.py --model best_model.pth --out_dir .
```
Скрипт сгенерирует:
* `neural_weights.bin` — бинарный массив Float32 весов (всего **~36.8 КБ**).
* `neural_weights.js` — готовый ES-модуль для импорта в Three.js.
* `neuralSurrogateShader.glsl` — шейдерная функция прямого прохода.
